# Mental Health Support Chatbot 🤖🧠

This is an AI-powered chatbot designed to provide basic mental health support through empathetic conversation and emotional understanding using NLP and machine learning.

## 🔍 Features
- Emotion classification using DistilBERT
- Real-time chatbot interaction (via CLI or messaging platforms)
- Sentiment-aware supportive responses
- Mental wellness tips and exercises

## 🧠 Technologies Used
- Python
- Hugging Face Transformers
- Flask (optional)
- Scikit-learn, NLTK, Seaborn, Matplotlib
- Telegram or Twilio (optional for chatbot deployment)

## 📦 Installation
```bash
git clone https://github.com/yourusername/mental-health-chatbot.git
cd mental-health-chatbot
pip install -r requirements.txt
python app.py
```
